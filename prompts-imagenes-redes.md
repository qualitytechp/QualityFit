# Prompts para imágenes promocionales — QualityFit (Fit Club y plantillas)

Guía de marca para todos los prompts:
- Marca: **QualityFit**, software moderno para gimnasios, yoga y boxing.
- Colores: rojo marca `#D92B12` (acento), negro `#000000` y grises/zinc para fondos, blanco para texto.
- Estilo: fotos realistas de alto impacto, iluminación de estudio, vibe energética y premium.
- Logotipo de QualityFit pequeño en esquina (si el generador lo permite) o dejar espacio para montarlo después.
- Formatos sugeridos (redes):
  - Feed Instagram/Facebook: **1:1 → 1080x1080**
  - Story / Reels: **9:16 → 1080x1920**
  - Portada LinkedIn: **1.91:1 → 1200x630**

Cómo usar: copia el texto del prompt (en inglés, que es como mejor responden las IAs) y pega en tu generador. Cambia `--ar` (Midjourney) o el tamaño según el formato.
